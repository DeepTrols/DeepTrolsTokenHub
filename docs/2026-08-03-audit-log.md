## 问题

`audit_logs` 表已建（000001 迁移），但 **零 Go 代码写入**。所有管理操作（建模型/加凭证/改租户状态）无审计痕迹，合规缺口。

## 修复

### `internal/handler/middleware/audit.go`（新增）
- `recordAudit`：插入 audit_logs（失败仅记日志，不阻塞业务）
- `AuditAdminWrite(pool)` 中间件：自动记录 admin 路由的 POST/PUT/DELETE 写操作
  - actor 从 JWT context 提取
  - action = "HTTP_METHOD /path"
  - resource_type 从路径第 2 段推断（如 /api/admin/tenants → tenants）
  - resource_id 从路径中的 UUID 提取
  - 记录 IP

### `cmd/api/main.go`
- admin 路由加 `AuditAdminWrite` 中间件（覆盖所有 admin 写操作）
- 新增 `GET /api/admin/audit` 读取端点

### `internal/handler/console/audit.go`（新增）
- `HandleListAuditLogs`：admin 读审计日志（分页）

### 测试
- `audit_integration_test.go`：真实 DB 验证 admin POST 产生 audit 记录

---

## 设计

- **一条中间件覆盖所有 admin 写操作**（无需逐个 handler 埋点）
- 审计写失败不影响业务操作（记录日志继续）
- GET 读操作不记录（避免噪音）
