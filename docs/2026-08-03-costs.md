# 成本核算功能 — 完成

> 日期: 2026-08-03
> 依据: 确认自营 Token 转售模式，利润 = 售价 - 上游成本，成本侧此前是盲区
> 结果: **后端 28 包 + 前端 182 测试全绿**

---

## 背景

用户确认系统是**自营 Token 转售平台**（非 OEM 多租户），运营核心是**利润 = 售价 - 上游成本**。此前 `upstream_cost` 已写入 usage_logs 但无聚合报表，成本侧是盲区。

## 实现

### 后端 `internal/handler/console/costs.go`
- `HandleCostSummary`：`GET /api/admin/costs`
  - 按模型聚合：`final_cost`（售出）+ `upstream_cost`（上游成本）+ `COUNT`
  - 计算利润 `profit = final - upstream`（decimal，禁 float）
  - 计算利润率 `profit_margin %`
  - 可选时间范围过滤 `?from=YYYY-MM-DD&to=YYYY-MM-DD`

### 前端 `web/src/pages/Costs.tsx`
- 汇总卡片：售出总额 / 上游成本 / 利润 / 利润率+调用量
- 分模型表格：调用量 / 售出 / 成本 / 利润 / 利润率（颜色分级）
- 三态（加载/错误/空）

### 路由
- `cmd/api/main.go`：`GET /admin/costs`
- `web/App.tsx`：`/admin/costs`
- `AdminLayout.tsx`：「成本核算」导航项

## 观察（重要）

当前所有模型 `profit = 0`（final_cost == upstream_cost），说明**定价 = 成本，无加价**。要盈利需要：
1. 调整 `model_pricing` 表的价格（售价 > 上游成本）
2. 或引入加价率/阶梯折扣

这是运营决策，非代码缺口。
