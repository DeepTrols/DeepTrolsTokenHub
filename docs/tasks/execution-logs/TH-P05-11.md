## 4. Live 双进程竞争探针（真实租约语义对现实验证）

探针数据库 `deeptrols_p0511_probe`（36 迁移 / 39 表）上同时启动两个
`./worker` 实例（真实 Redis :16380，`WORKER_METRICS_ADDR` 分别为
127.0.0.1:19090 / 127.0.0.1:19091）：

- 实例 A：4 个可观测 worker（`billing_sync` / `health_checker` /
  `subscription_expirer` / `subscription_renewer`，覆盖启动周期 + 60s tick）
  全部 `worker_cycles_total{outcome="success"}` +
  `worker_lease_total{outcome="acquired"}`，duration 计数同步增长。
- 实例 B：同 4 个 worker 全部 `outcome="skipped"`，日志行
  `lease not acquired (another instance is leader); skipping cycle`
  （与 TH-P05-08 记录的跳过日志风格一致）。
- `redis-cli` 观测 `worker:lease:*` 键存活且带 TTL（观测样本 295s / 205s / 15s，
  与 5min / 50s TTL 一致）。
- 恰好一次执行：全程无重复周期；探针结束后端口 19090/19091 释放。
- 附加证据：首轮探针曾出现 metrics 端口被残留进程占用 → 实例 A 日志
  `worker metrics server failed` 但**周期照常执行**，实测了
  「绑定失败只降级可观测性」的设计。

## 5. Metrics Inventory（本批次新增家族）

| 指标 | 类型 | 标签 | 备注 |
|---|---|---|---|
| `worker_cycles_total` | Counter | `worker`, `outcome` | outcome ∈ success/failed/panic_recovered/skipped |
| `worker_cycle_duration_seconds` | Histogram | `worker` | buckets 0.05/0.1/0.25/0.5/1/2.5/5/10/30/60/120/300/600 |
| `worker_lease_total` | Counter | `worker`, `outcome` | outcome ∈ acquired/skipped/error；Redis 错误 fail-closed |

- 复用 TH-P05-04 的 `metrics.Default` registry——**无第二 registry**；
  worker 家族与网关/资金家族同一暴露面约束（无 Go runtime 采集器）。
- `AllowedWorkers` = health_checker / reconciler / billing_sync /
  subscription_expirer / subscription_renewer；`SanitizeWorker` /
  `SanitizeCycleOutcome` / `SanitizeLeaseOutcome` 白名单钳制 → `other`。
- setter 全部经 `safely()` 包裹：指标故障永不改变租约结果、不重复执行
  worker、不阻塞周期（TH-P05-04 结构性保证的直接延伸）。
- Worker 进程 `/metrics`：`serveWorkerMetrics`（`WORKER_METRICS_ADDR`，
  默认 `127.0.0.1:19090` 仅回环；空值禁用；绑定失败仅降级可观测性）。

## 10. 对 TH-P05-05 的交接（Silence 基础）

计数器 + 固定调度周期足以构造沉默检测，无需新增时间戳指标：
`increase(worker_cycles_total{worker="<name>",outcome="success"}[<window>]) == 0`
（窗口取周期 2–3 倍；60s 级：health_checker / billing_sync；1h 级：
reconciler / subscription_expirer / subscription_renewer）。
聚合必须按 `worker` 标签（不带实例维度），避免把租约竞争下的健康
`skipped` 误判为沉默。本批次**未**新增 `last_success_timestamp_seconds`
gauge：AC 未要求。告警规则本身属 TH-P05-05 范围，本轮不定义。
