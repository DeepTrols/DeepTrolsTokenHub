# 官方模型价目参考（2026-08-24 核实）

> 用途：作为「模型管理」界面手动录入/核对价格的参考资料。计费严格按界面显示的价格计算，
> 本文件不是计费数据源，仅帮助人工维护时对照官方价。

## 系统计费口径（录入前必读）

- token 类维度（input / output / cache_read / cache_write / reasoning）在系统里统一按
  **元 / 百万 tokens** 存储并计费；图片/音频等非 token 维度按单个单位计费。
- 计费引擎每次实时读取 `model_pricing` 的 sell 行（售价），改价立即生效；只有 cost 行时按
  真实成本计费（界面会提示"仅有成本价，售价按真实成本实时计算"）。
- 当前统一维护人民币（CNY）。官方价若是美元，录入前需自行换算为人民币。
- 阶梯计价、Batch 半价、缓存折扣等复杂规则当前单维价格表表达不了，按最常用档位录入即可。
